# Security Policy

## Current status

GitHub private vulnerability reporting is not enabled for this repository, and no confidential reporting channel has been published. This file describes that situation as it is, and makes no promise of a private channel, a response time, or support.

## If you found a vulnerability

- Do not post exploits, proofs of concept, secrets, or tokens in public issues, pull requests, or comments.
- You may open a public issue that contains no technical details, and use it only to request private coordination. State that you have a security report and nothing more.
- Such an issue is only a request. It is not confidential disclosure, and anyone can see it.

## What is pending

Setting up a real private channel is outstanding work for the maintainers. This file will be updated once that channel exists.
